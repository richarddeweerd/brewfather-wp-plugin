# Glossary

## User levels

Ordered low to high: **Visitor** < **User** < **Brewer** < **Admin**. Each level can do everything the levels below it can do.

- **Visitor**: someone on the website who is not logged in to WordPress.
- **User**: a logged-in WordPress user.
- **Brewer**: a logged-in WordPress user who belongs to the brewers group.
- **Admin**: a logged-in WordPress administrator.

## Brewfather data

- **Recipe**: a beer recipe as defined in Brewfather.
- **Batch**: one brew of a Recipe, as recorded in Brewfather. Several Batches can share the same Recipe.
- **Ingredients**: the fermentables, hops, yeasts and other additions that make up a Recipe.
- **Stock**: the amount of each ingredient currently on hand, as kept in Brewfather's inventory. Only Brewers and Admins can see Stock.
- **Batch note**: a comment that a User or higher adds to a Batch on the website. Batch notes belong to the website, not to Brewfather.
